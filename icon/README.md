# NOCTURNE launcher icon

The launcher artwork is based on the supplied monochrome luminous-cross reference.

- `res/mipmap-anydpi-v26/` contains adaptive launcher icon declarations.
- `res/mipmap-*` contains legacy density-specific launcher PNGs and safe-zone foregrounds.
- `nocturne-icon.svg` is the editable vector reference.
- `app/src/main/python/kolom/nocturne-logo.png` is used by the in-app header and sign-in screen.

The adaptive icon uses a near-black background and a centered luminous mark so launchers can apply their own icon mask without cutting off the rays.
